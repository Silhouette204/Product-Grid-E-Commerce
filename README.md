# 🖥️ TechForge | Custom PC Parts E-Commerce Store (WIP)<br>
A modern, responsive frontend e-commerce web application dedicated to computer hardware components. This project simulates a complete user shopping workflow from browsing premium components to generating dynamic virtual invoices.

* **📦 Dynamic Product Grid:** Renders computer components (GPUs, Keyboards, Processors) efficiently using modular JavaScript data.
* **🛒 Interactive Shopping Cart:** Features a sleek "Push Layout" sidebar mechanism for desktop views and scrolling locks for mobile optimization.
* **📝 Simulated Checkout Workflow:** A modal form capturing customer data, addresses, and simulated payment confirmation.
* **🧾 Virtual Receipt Generator:** (Upcoming) Generates an ASCII-style custom business receipt equipped with simulated tax/shipping logic and a dynamic QR code scanner.

## 🛠️ Tech Stack

* **Bundler:** [Vite](https://vitejs.dev/) (For ultra-fast frontend tooling)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Utility-first framework utilizing custom gradients and dark themes)
* **Logic:** Vanilla JavaScript (ES6 Modules for scalable code structures)
* **Icons:** FontAwesome v6

## 📂 Current Module Architecture

```text
├── index.html
├── src/
│   ├── js/
│   │   ├── cart-ui.js                # Handles shopping cart rendering & transitions
│   │   ├── product-render-products.js # Dynamic product data rendering
│   │   └── main.js                   # Application bootstrap and core events
│   └── css/
│       └── style.css                 # Custom Tailwind directives
```
